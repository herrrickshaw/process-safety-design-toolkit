# Safety-feature checklist for the nine conceptual P&ID sets

Date: 2026-11-11. Scope: free, readable sources for the safety features a conceptual P&ID should carry; status of each feature in the current sets taken from `docs/pid/validation/*_VALIDATION.md` (the LPG set has no validation report, so its status is mostly 'unknown'). Screening aid, not a design: this checklist says what to show and where the free source supports it, not how to size it.

Grades: A = the document's text was fetched and read; C = search snippet only. Status: present / partial / missing / not assessed (the validator did not look) / unknown. Facts are short paraphrases; no standard text is reproduced.
