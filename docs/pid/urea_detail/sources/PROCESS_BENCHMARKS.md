# Process benchmarks for the coal-to-urea unit P&ID package (Rev C0)

Date: 12 Nov 2026. Compares package values (registers and AREA notes) with PUBLIC documents that were downloaded and read as text. Grade A = the document text was read with `pdftotext -layout`; C = search snippet only (no value from a C source is used for a verdict other than a flag). Screening comparison only: deviation = (ours - source) / source. Verdict: agrees (within 10 % or inside the source range), explained (a stated reason found in a source or in the package notes), unexplained (no reason demonstrated). Several 'explained' reasons are my reading and are marked in the note.

Fetch: curl with browser User-Agent into `/private/tmp/claude-501/src_proc/`, about 1 request per second per host. No CAPTCHA, login or WAF wall was met. One host (coal.gov.in) refused the connection and was not retried or bypassed.

## Which Rev B conflicts in PACKAGE_README.md the sources help resolve

1. Syngas 181.5 C / 41 bar vs Rev B 350 C / 45 bar into R-201: NETL Case 6 scrubber exit 191 C, shift feed 39.6 bar (S1); Talcher PFR water-quench and scrub exit about 206 C (S6). Neither supports 350 C. Resolved in favour of reheat or steam addition upstream of R-201.
2. Stream 306 vs 4 (15.4 t/h steam): partly. NETL adds steam to H2O:CO 1.8 (S1), ours runs 1.2 (derived), so stream 6 should not simply drop by 15.4 t/h. Needs a shift-side re-balance.
3. ASU power 61.7 vs 36.8 MW: resolved in favour of the bottom-up figure. The Shell-type reference needs 680 kWh/t O2 for the full train (S1); Rev B 275 has no support.
4. Mill dries to 2 %: NETL feeds coal at 5 % moisture (S1 Ex. 3-74). Direction supported, 2 % is aggressive; no BAT source for the mill outlet moisture was found.
5. Single bed cannot give shift conversion: NETL gets 97.8 % in two reactors but at 1.8 H2O:CO (S1); ours uses 1.2. Raising the steam ratio is the lever to test before accepting a 505 C bed.
6. Acid gas and methanator: acid gas is 34 mol % H2S with 51 % CO2 in the Selexol case (S1), confirming the finding. Talcher uses Rectisol plus a nitrogen wash, no methanation (S5, S6), supporting ISD 3.
8. Steam and cooling water: Talcher raises steam in coal boilers (2+1 x 350 t/h) because its gasifier is a quench type (S6). Our 369 t/h syngas-cooler steam is a different configuration, not a Talcher feature.
Not helped: 7 (stream 27 temperature) and 9 (flare loads).

## Additional findings not in the README

- Gasifier carbon conversion is 90 % in the repo (C_CONV) against 99.5 % (NETL) and at least 98.8 % in every Buggenum test (S8). This probably drives the low cold-gas efficiency and the high coal tonnage.
- Feed tonnage is 63 % above Talcher's own EIA figure for the same gas volume (200 kNm3/h CO+H2 vs ours 216). Total coal including boiler fuel is closer (-6 to -15 %).
- The urea reactor conditions (150 bar, 180 C, N/C 3.5) are the NH3-stripping set, not CO2 stripping (S4).
- Converter exit NH3 is 10.4 mol % in ours against 16.9 % in the Talcher PFR.
- Talcher documents disagree with each other on coal (PFR 249.6 MTPH ROM coal in Sec 0.13 vs 240.2 from Table 3.2; annual 3.5-4.5 Mt/y vs about 2.1 Mt/y implied vs ICRA 3 Mt/y), so Talcher is a +/-10 % reference at best.
