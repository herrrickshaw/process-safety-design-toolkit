# Technology and sizing sources for the coal-to-urea P&ID package (Rev C input)

Companion to `SAFETY_SOURCES.md`. Purpose: replace screening assumptions (tag A) in `AREA_10..90_NOTES.md` with public technology and sizing values. Machine-readable copy: `TECHNOLOGY_SOURCES.csv` (same rows, same ids T01-T56).

Date of work: 2026-11-12. Every document below was fetched with curl (browser User-Agent, 1 request per second per host), converted with `pdftotext -layout` (or tag-stripped HTML) and read; local copies are in `/private/tmp/claude-501/src_tech/` (may be wiped; the `url` column is the durable locator). No vendor data sheets, licensed standards or licensor-proprietary data were used. Licensor names appear only as public names.

Grades: **A** = public document read in full text, number is that document's own data or statement; **B** = document read but the figure is derived by us, quoted from another work, or test-scale; **C** = search snippet only, not read. Relation: *consistent* = our value inside the source range; *partial* = overlaps or only supports; *contradicts* = our value or range is outside the source; *context* = informs but does not replace.
