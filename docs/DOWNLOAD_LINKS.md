The only process-safety-related items found: a Shell "TSE 101 module 1.3, Fire, Release, Explosion, Dispersion (FRED) and Toxicity" training deck (Shell Projects & Technology, Oct 2014, marked RESTRICTED; qualitative, no equations; not copied here), an Anderson Greenwood reserve-capacity relief-valve data sheet, a PSM flame sheet, an API 521 heat-input slide (43.2 F A^0.82) in an NG-processing safety course, and Molkov's hydrogen hazards paper.
